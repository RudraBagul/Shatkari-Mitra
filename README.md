# Shatkari-Mitra
Developed Shetkari Mitra, an AI-powered agricultural decision-support platform to prevent farmers' distress selling by predicting 7-day mandi prices using LightGBM, achieving 18.03% MAPE (52.97% prediction accuracy improvement over SARIMA), with crop-decay analysis and Marathi voice recognition for smarter selling decisions.
